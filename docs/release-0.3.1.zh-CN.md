# Codex Design Bridge 0.3.1

完整版本：`0.3.1+codex.20260731050635`

## 本版重点

- 新增 Windows 干净升级入口 `Install Codex Design Bridge.cmd`。
- 安装前检查 Codex/ChatGPT 是否仍在运行，避免覆盖被锁定的旧缓存。
- 升级前备份旧个人插件源码；失败时尝试自动恢复。
- 安装后同时核对个人源码、Codex 运行缓存、插件列表和核心文件 SHA-256。
- 在个人插件目录旁生成 `.codex-design-bridge-install-report.json`。
- 工作台显示 `v0.3.1`；悬停可查看运行版本、源码版本和加载来源。
- 运行缓存与个人源码不一致时，工作台直接提示完整退出、重新安装并新建任务。
- 修复浏览器把小写内联 `<svg>` 识别成普通 Frame 的问题；相邻的灰色、红色等自制 SVG 会分别作为可编辑 SVG 节点发送到 Figma。

本版不新增设计元素类型。0.3.0 的已有内联 SVG 回写与 Figma 新建直接矢量插入能力保持不变。

## 安装

1. 保存工作并完整退出 Codex/ChatGPT，包括后台进程。
2. 解压完整发布包。
3. 双击 `Install Codex Design Bridge.cmd`。
4. 看到安装完成提示后重新打开 Codex。
5. 新建任务并打开 Design Bridge，确认顶部显示 `v0.3.1`，版本提示没有警告。

若安装程序提示 Codex 仍在运行，不要强行删除缓存；退出相关进程后重新运行即可。
