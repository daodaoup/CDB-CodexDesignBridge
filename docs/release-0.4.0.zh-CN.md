# Codex Design Bridge 0.4.0

完整版本：`0.4.0+codex.20260731061842`

## 主要更新

- 同源、项目内的 `<img src="./graphic.svg">` 会在页面捕获时展开为一个可编辑 SVG 节点。
- 在 Figma 修改后，安全的完整 SVG 会直接写回原 `.svg` 文件；HTML/JSX 中的 `<img>` 引用保持不变。
- 线性/径向渐变、`mask`、`clipPath`、本地 `url(#id)`/`href="#id"`、安全 `<style>` 和 SVG 文字进入统一往返校验。
- Figma 中新建的组合可以同时包含支持的矢量和文字，发送时生成一个 `svgInsert`，不再误报为页面结构变化。
- 普通页面区块增删、层级重排和组件替换仍保留为待处理差异，不自动覆盖前端。
- 本地 Figma 连接协议升级为 5；旧插件窗口会明确提示版本不匹配。
- Windows 安装包的核心哈希清单增加页面与 SVG 校验模块。

## 安全边界

仅展开同源、路径以 `.svg` 结尾且不超过 768 KB 的资源。脚本、事件处理器、外部网络引用、嵌入图片、`filter`、`pattern`、`marker` 和超限导出不会进入快速写回。

外部 SVG 必须能映射到项目内的真实 `.svg` 文件，路径必须留在项目根目录内。无法确定源码文件时会保留为待处理差异。

## 安装

1. 保存工作并完整退出 Codex/ChatGPT，包括后台进程。
2. 解压完整发布包。
3. 双击 `Install Codex Design Bridge.cmd`。
4. 确认安装报告中的版本为 `0.4.0+codex.20260731061842`，七个核心文件校验通过。
5. 重新打开 Codex，并新建任务。
6. 关闭并重新运行 Figma 中的 Codex Design Bridge 开发插件；manifest 路径没有变化时无需重新导入。
7. 确认工作台显示 `v0.4.0`，且运行版本与个人源码版本一致。
